# AUTO DJ AI

Cross-platform DJ application prototype. This app is intentionally isolated from the existing JARVIS app.

## Run
```bash
cd auto-dj
npm install
npx expo start
```

Press `w` for web, or scan the Expo Go QR code for a compatible iPhone or Android device.

## Current status
The first screen is an interactive UI prototype with demo tracks and local UI state. It does not yet play audio. Local-file access, playback/mixing, BPM analysis, and platform/provider integrations are subsequent milestones.

See the repository-level `AUTO-DJ-AI-PLAN.md` and `AUTO-DJ-AI-ROADMAP.md`.
